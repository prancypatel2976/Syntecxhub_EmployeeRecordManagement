# Employee Record Management System

## Project Description

Employee Record Management is a Java console-based application developed using Java Collections.
The system allows users to manage employee records efficiently.

## Features

* Add employee
* View all employees
* Search employee by ID
* Update employee details
* Delete employee
* Prevent duplicate employee IDs

## Technologies Used

* Java
* Eclipse IDE
* ArrayList
* HashSet
* HashMap
* Java Collections Framework

## Collections Used

### ArrayList

Used to store and display employee records.

### HashSet

Used to maintain unique employee IDs.

### HashMap

Used for fast employee lookup using employee ID as the key.

## How to Run

1. Open the project in Eclipse.
2. Open Main.java.
3. Right-click Main.java.
4. Select Run As.
5. Select Java Application.
6. Use the console menu to manage employee records.
